# Staging

This directory holds Git-tracked candidate Markdown for owner review before durable ingestion. A staged candidate is not canonical knowledge and must not be treated as verified merely because it is saved, committed, liked, or approved for later work.

Keep source URLs and capture context when available, avoid secrets and unnecessary personal data, and use a descriptive lowercase-kebab-case filename. Promote candidates only through an explicit **Brain this** action; preserve provenance and do not delete the staged copy without owner approval.

For repeated or corrective runtime observations, follow `skills/observation-promotion/SKILL.md` and start from `staging/observation-template.md`. Consolidation may produce a staged proposal but may never write canonical knowledge automatically.
