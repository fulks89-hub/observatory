# TL;DR

A context graph retains the circumstances around a relationship—not merely that X relates to Y, but who said so, where, when, how confidently, and whether later evidence conflicts.

# How it works

Observatory first encodes context through OKF provenance/lifecycle metadata and intelligible prose around [knowledge-graph](knowledge-graphs.md) links. A richer database remains a rebuildable projection.
