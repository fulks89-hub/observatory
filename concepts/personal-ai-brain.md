# TL;DR

A personal AI brain is not model chat history. It is a user-owned, durable representation of learned concepts, evidence, ideas, links, uncertainty, and questions that replaceable agents can improve.

# How it works

Observatory combines [OKF](open-knowledge-format.md) Markdown as truth, Git as memory, contextual links as a [knowledge graph](knowledge-graphs.md), and a repeating [knowledge loop](knowledge-loops.md). [Agent memory](agent-memory.md) and retrieval systems are clients, not owners.
